# Field Track interface

## Direction

Field Track is an operational product: dense, calm, and explicit about signal
quality. The manager surface uses warm paper and white work surfaces, deep green
actions, lime identity accents, and amber/red only for real warnings. Android
uses the same hierarchy through platform-native touch sizes and system text.

## Interaction rules

- Keep roster, map, and employee detail available without walkthroughs.
- Use one primary action per task. Onboarding expands inline and reveals the
  enrollment code once; it does not interrupt monitoring with a modal.
- Never communicate freshness, retention, enrollment, or SIM state by color alone.
- Dashboard controls remain keyboard accessible; Android touch targets are at
  least 48 dp and respect font scaling.
- Preserve routes, navigation labels, legal/privacy wording, and the visible
  Android tracking notification.

## Core tokens

- Background `#f4f1e8`; surface `#fffdf8`; ink `#17241f`; muted `#607069`.
- Primary `#153f36`; secondary green `#216c59`; identity lime `#c5df70`.
- Warning `#c27b21`; error `#b64738`; focus `#3d82aa`.
- Surface radius 12–16 px, control radius 8–11 px, one soft offset shadow.
- Manager headings use Manrope; body uses DM Sans/system. Android uses the
  platform system family with explicit title/body/label roles.

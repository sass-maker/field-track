# Field Track Precise footer fonts

These exact OFL-licensed Geist, Geist Mono, and Newsreader WOFF2 files support the published Precise footer's UI, label, and signature roles. Source URLs, SHA-256 hashes, and license filenames are recorded in `provenance.json`; the matching OFL texts accompany the unmodified font binaries. Fonts are served from the same origin, with no runtime Google Fonts request from the footer.
